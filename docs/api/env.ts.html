env.ts

The env host module: the environment of the running process, as an import rather than a global.

An Env is read-only and holds a snapshot taken when this module loads, the runtime's fixed environment: a write to the global's process.env afterward changes nothing here, and only names listed by env.narrow reach a narrowed handle. A name outside its set throws not_granted, so a denial is never read as a variable that's unset, which is undefined from get. Library edges take plain records, built at a root from get_all. An environment value can be a secret: this module prints none, its errors naming the variable, never the value, so what a value becomes after a read is up to the caller.

Handles and their prototypes are frozen, null-prototype so none of them is thenable even with a polluted Object.prototype.then, and constructing one takes a key only this module holds. A method called on any other object throws TypeError, private fields being the only state.

This is the Node implementation, which runs on the Node Gro. Its gaps against the runtime's builtin, which it documents rather than the API weakening to match:

  • The global process stays, and any module can read process.env, so a narrowed Env bounds only code that uses it, a review signal, not a boundary.
  • The root Env allows every name, where the runtime's holds only the granted ones (every name under fgro run -A) and a name outside them throws not_granted.
  • A not_granted is only thrown here, where on the runtime it also fails the run, even when the program catches it.
  • The snapshot is taken at this module's load, so a write to process.env before that shows.

get

A variable's value, undefined when it's unset. Own names only, so toString is unset.

type (name: string): string | undefined

name

type string
returns string | undefined

throws

  • TypeError - for a name that isn't a non-empty, well-formed string without NUL or `=`
  • EnvError - `not_granted`, a name outside this handle's set

get_all

Every variable this handle allows that's set, a frozen null-prototype record. Pass it, or part of it, where a library takes a plain record.

type (): Readonly<Record<string, string>>

returns Readonly<Record<string, string>>

narrow

A handle limited to names, each an exact, case-sensitive name, never a glob, so a holder of the handle can't enumerate more than it's given. A name that's unset stays in the set, as undefined from get. It can only shrink.
