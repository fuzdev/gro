InvokeTask
#

task.ts view source

InvokeTask import type {InvokeTask} from '@fuzdev/gro/task.js';

Invokes a task: a name always means a builtin, and a path always means a task file, relative to the cwd and ending in .task.ts or .task.js.

Literal names and paths are checked against TaskRegistry and args against the task's Args schema input. A literal task path not in the registry, or a name widened to string, takes loose Args.
