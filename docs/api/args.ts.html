args.ts

The args host module: the arguments after the script, as an import rather than a global.

args is a frozen array read when this module loads, what a script given to gro run receives and what a bare node script.ts receives. In the CLI's own process they're the CLI's args, the task name included, since a task's parsed args are its context's task_args.

args is no handle but a real array, frozen, so its prototype is the unfrozen Array.prototype and awaiting it adopts a polluted then.

This is the Node implementation, which runs on the Node Gro. Its gaps against the runtime's builtin, which it documents rather than the API weakening to match:

  • The global process stays, and any module can read process.argv.
  • args under node -e and node -p reads the undocumented process._eval, as no documented API says the process has no script.
