spawn_error.ts

The errors of the spawn host module (spawn.ts), apart from it.

Making or matching an error starts no process, so this module grants nothing: code that only classifies a failure, or builds one, imports it without linking the host module, and a mock of the host module throws the same errors it does. The class and its prototype are frozen.

import {SpawnError} from '@fuzdev/gro/spawn_error.js';

The error spawn.ts throws when a program can't be reached or started, typed by kind. A program that started and exited non-zero is a result, not this error. Match it with is_spawn_error, which also recognizes one from another copy of Gro. The class and its prototype are frozen.

SpawnErrorKind

type "not_found" | "not_executable" | "not_granted" | "launch_failed"

import type {SpawnErrorKind} from '@fuzdev/gro/spawn_error.js';

Why a program couldn't be reached or started. not_found is a name that resolves to no regular executable; not_executable is a regular file without execute permission, or one the module refuses (.bat, .cmd, a format that's neither #! nor ELF); not_granted is a name outside what the handle allows, or an environment a narrowed root can't give; launch_failed is a pinned program that couldn't start, its cause on cause, including one that wasn't started because the call's signal had already aborted.
