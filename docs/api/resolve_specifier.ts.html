resolve_specifier
#

resolve_specifier.ts view source

(specifier: string, importer: PathId): Promise<ResolvedSpecifier> import {resolve_specifier} from '@fuzdev/gro/resolve_specifier.js';

Resolves a relative or absolute import specifier to exactly the file it names, the rule gro's runtime resolver follows: extensions are mandatory, nothing is probed, and .js never maps to .ts. The specifier is read as a filesystem path, never URL-decoded; ?raw is the only query recognized.

specifier

a relative or absolute path, optionally ending in ?raw

type string

importer

the path of the importing module

type PathId

returns

Promise<ResolvedSpecifier>

throws

  • if - the specifier doesn't name an existing file, with the fix when there is one, `code` `'ERR_UNSUPPORTED_DIR_IMPORT'` for a directory or else `'ERR_MODULE_NOT_FOUND'`, and the path's `url` (with any `?raw`), as Node sets them; any other filesystem error (like `EACCES`) is rethrown naming the specifier and importer, the original as `cause`
