gen_task_registry
#

task_registry.ts view source

GenConfig import {gen_task_registry} from '@fuzdev/gro/task_registry.js';

The genfile config that types a project's tasks for invoke_task. Export it as gen from a genfile like src/gro_tasks.gen.ts, which writes src/gro_tasks.ts augmenting ProjectTasks. In gro dev it regenerates when a task file is added or changed; gro dev ignores deletes, so run gro gen after removing a task.

ProjectTasks
#

task_registry.ts view source

ProjectTasks import type {ProjectTasks} from '@fuzdev/gro/task_registry.js';

The project's own tasks by name, empty until augmented by a generated file. Create a genfile like src/gro_tasks.gen.ts exporting gen_task_registry as gen to type the project's task names and args for invoke_task.
