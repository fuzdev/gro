to_plugin_context
#

plugin.ts view source

<TArgs>(ctx: TaskContext<TArgs>, dev: boolean, watch: boolean): PluginContext<TArgs> import {to_plugin_context} from '@fuzdev/gro/plugin.js';

Widens a TaskContext to a PluginContext by adding dev and watch. Copies property descriptors rather than spreading, because svelte_config is a lazy getter - spreading would call it, resolving the Svelte config even for a plugin set that never reads it, and pinning whichever promise it returned instead of the memoized one.
